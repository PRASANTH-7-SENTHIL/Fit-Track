# Fit-Track

FitTrack AI is a full-featured fitness, nutrition, and workout tracking web application powered by Next.js, React, Tailwind CSS, and Firebase.

## Features
- **Dashboard & Analytics**: Track calories, macros, workouts, and daily fitness metrics.
- **Activity & GPS Tracker**: Step tracking, running sessions, and active duration.
- **Nutrition & Food Diary**: Meal logging with nutritional breakdowns.
- **Workout Sessions**: Customizable workout plans and exercise logs.
- **Body & Weight History**: Weight progress charts and measurement tracking.
- **AI Fitness Assistant**: AI-driven daily fitness recommendations and reports.

## Project Structure
- `web/`: Next.js 16 application source code, components, routes, and styles.

## Getting Started

1. Navigate to the web application directory:
   ```bash
   cd web
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
